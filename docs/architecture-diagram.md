## AWS Services Summary

| Category | Service | Purpose |
|----------|---------|---------|
| **ML/AI** | SageMaker | Training jobs, Batch Transform, Model artifacts |
| | ECR | XGBoost container images |
| **Compute** | Lambda | Model monitoring, GitHub webhook triggers |
| **Storage** | S3 | Raw data, features, models, predictions (4 buckets) |
| **Security** | IAM | Roles, policies, OIDC provider |
| | Secrets Manager | GitHub token for webhook triggers |
| **Monitoring** | CloudWatch | Metrics, alarms, dashboards, log groups |
| | SNS | Alert notifications, training triggers |
| **Orchestration** | EventBridge | Scheduled retraining, monitoring triggers |
| | SSM Parameter Store | Pipeline configuration |

## Key Thresholds

| Metric | Threshold | Action |
|--------|-----------|--------|
| Model F1 Score | < 0.75 | Block deployment |
| Model Latency | > 5000ms | Trigger alert |
| Error Count | > 10 | Trigger alert |
| Training Timeout | > 1 hour | Fail job |
| Transform Timeout | > 30 min | Fail job |
| Monitoring Interval | 15 min | Lambda execution |
| Retraining Schedule | Weekly (Mon 2 AM) | Trigger pipeline |
